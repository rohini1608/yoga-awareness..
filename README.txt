HOW TO ADD TO YOUR EXISTING GITHUB WEBSITE
1. Open your repository: rohini1608/Yoga-Awareness.
2. Open the repository's main folder (the same folder where your existing index.html is).
3. Upload week1.html, week2.html, week3.html, week4.html, week5.html, week6.html and style.css.
4. If you already have an index.html, DO NOT replace it with the sample index.html in this package. Instead, open your existing index.html and replace only the Weekly Activities section with the snippet below.
5. Commit the changes. Open your GitHub Pages website and click each week.
